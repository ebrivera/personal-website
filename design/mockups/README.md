# Redesign mockups

Static HTML mockups for the ebrivera.com redesign. Open a file directly in a browser; nothing here is part of the Next.js build.

- `round-4.html`: the chosen direction. A calm one-column home (name, blurb, welcome, nav, experience, contacts). Clicking a nav item slides the column into a skinny left sidebar while the page slides in from the right. Thin Spotify-style bar at the bottom. Light palettes only. Dashed `write:` boxes are copy still to be written.
